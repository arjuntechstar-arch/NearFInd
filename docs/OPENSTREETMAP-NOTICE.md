# OpenStreetMap data notice

NearFind can ingest nearby place data from OpenStreetMap through a configured Overpass endpoint.

Contains information from OpenStreetMap, which is made available under the Open Database License (ODbL). Copyright remains with OpenStreetMap contributors.

- Copyright and attribution: https://www.openstreetmap.org/copyright
- ODbL license: https://opendatacommons.org/licenses/odbl/

NearFind keeps the source provider and external feature identifier for imported records, displays OpenStreetMap attribution when OSM-derived results are shown, and treats imported records as refreshable source data rather than NearFind-owned business data.

Production deployments must use a self-hosted or commercial Overpass-compatible endpoint appropriate for application traffic. Public community Overpass instances are intended for fair/shared use and are not configured as a production dependency by NearFind.
